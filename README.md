# Metal Detector Project

## Overview

This project focuses on the design, simulation, and physical implementation of a basic metal detection system.

The circuit was initially designed and tested in **NI Multisim** to verify its functionality. After successful simulation, the circuit was implemented using physical electronic components and tested as a working hardware prototype.

## Project Objectives

- Design a functional metal detection circuit
- Simulate and validate the circuit using NI Multisim
- Implement the circuit using physical electronic components
- Test the prototype under real-world conditions
- Develop practical skills in electronic circuit design and troubleshooting

## Tools and Technologies

- NI Multisim
- Electronic Components
- Circuit Simulation
- Hardware Prototyping
- Circuit Testing

## System Development

### Simulation

The circuit was developed and tested in NI Multisim before physical implementation. The simulation phase was used to analyze circuit behavior and identify potential issues.

### Hardware Implementation

Following successful simulation, the circuit was assembled using physical electronic components. The completed prototype was tested with metal objects to evaluate its detection capability.

## Project Outcome

The project demonstrates the complete development process of a basic metal detection system, from circuit simulation to physical hardware implementation.
